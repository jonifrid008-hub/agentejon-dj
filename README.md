# AgenteJon DJ Official

Quiero crear el sitio web oficial de mi proyecto como DJ llamado AgenteJon DJ.

IMPORTANTE:

No inventes experiencia, estadísticas, eventos, clientes, festivales ni lugares donde haya tocado.

No pongas frases como:

"Más de 250 eventos"

"100.000 personas"

"Clientes internacionales"

"Años de experiencia"

Porque todavía estoy construyendo mi carrera como DJ.

Quiero una página que transmita profesionalismo, pero también autenticidad.

El objetivo es mostrar quién soy, compartir mi música y que cualquier persona pueda conocer mi proyecto o contratarme.

La estética debe ser moderna, minimalista y elegante.

Toda la página debe estar completamente en español.

La identidad visual debe usar únicamente:

Negro (#000000)

Blanco (#FFFFFF)

Grises oscuros (#1A1A1A y #2A2A2A)

Usar mi logo como identidad principal.

No agregar otros colores.

No usar neones.

No usar efectos exagerados.

El diseño debe sentirse premium pero cercano.

Inspirarse en Apple, Porsche y páginas modernas de artistas.

No parecer una plantilla genérica.

INICIO

Pantalla completa.

Fondo oscuro con una imagen o video elegante relacionado con música electrónica.

Mi logo centrado.

Debajo:

AGENTEJON DJ

Y una frase sencilla como:

"La música es mi forma de conectar con la gente."

Botones:

Escuchar música

Contactarme

----------------------------------------

SOBRE MÍ

No inventar información.

Solo crear una estructura con texto editable.

Ejemplo:

"Soy AgenteJon DJ, un joven DJ apasionado por la música y por crear experiencias únicas. Este proyecto nació con el objetivo de compartir mi estilo, seguir creciendo y llevar mi música a cada vez más personas."

Agregar una foto grande.

----------------------------------------

MÚSICA

Crear una sección donde luego pueda agregar:

Spotify

SoundCloud

YouTube

Mixes

No inventar canciones.

Solo dejar espacios preparados.

----------------------------------------

GALERÍA

Crear una galería moderna para agregar fotos y videos de futuros eventos.

No agregar imágenes falsas de festivales gigantes.

Usar placeholders elegantes.

----------------------------------------

CONTACTO

Formulario con:

Nombre

Correo

Mensaje

Botón "Enviar"

Agregar botones para:

Instagram

TikTok

YouTube

WhatsApp

----------------------------------------

DISEÑO

Mucho espacio en blanco.

Animaciones suaves.

Fade al hacer scroll.

Navbar transparente que cambia a negro al bajar.

Botones elegantes.

Tipografía moderna.

Responsive para celular.

No agregar información falsa.

No inventar trayectoria.

No inventar clientes.

No inventar estadísticas.

La página debe sentirse como el comienzo de una marca profesional que irá creciendo con el tiempo.
